# FRACTURE

Experimental shader pack for the Aperture shader mod for Minecraft. 

## Information
- Only members of the Aperture closed beta will be able to try this.
- This project is currently under an All Rights Reserved licence while I decide how I would like to eventually license it.
- Contributions to this repository are currently **not** welcome.
- No generative AI is being used in the development of this project.

## Features

This shader pack currently implements the following techniques:
- Lighting
  - ReSTIR GI
  - Reflective Shadow Maps (RSM)
  - Ground-truth Based Ambient Occlusion (GTAO)
  - Specular reflections with Hi-Z SSRT or HWRT
  - Generally physically based shading approach
- Atmospherics
  - Raymarched atmosphere (following Hillaire's multiple scattering approach)
  - Volumetric clouds
  - Froxel-based volumetric fog
- Post-processing
  - Bloom
  - Histogram-based auto exposure
  - TAA
